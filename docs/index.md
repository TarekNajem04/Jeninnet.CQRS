# Jeninnet.CQRS

**Current preview:** `1.0.0-preview.1` (2026-11-22).

Source-generated CQRS for .NET: zero-reflection dispatch, durable deferred delivery, a
dead-letter store with replay, a notification outbox with transport relay workers, explicit saga
state machines with durable persistence, request/response over any transport, a persistent
message scheduler, multi-tenant dispatch with partitioned keys and EF query filters, validation
result adapters, distributed caching, resilience, ASP.NET Core endpoint mapping, zero-dependency
message contracts, MQTT/HTTP/SignalR transports, and `netstandard2.0` assets for every portable
package.
